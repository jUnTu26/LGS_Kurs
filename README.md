# Luna Glow Studio — Website

Statische Website. Alle Bilder und Schriften sind in die HTML-Dateien eingebettet.

```
index.html         Startseite
ueber-mich.html    Über mich
impressum.html     Impressum
datenschutz.html   Datenschutzerklärung
agb.html           AGB
widerruf.html      Widerrufsrecht
vercel.json        Vercel-Konfiguration
```

## Deploy

1. Alle Dateien dieses Ordners ins Root eines GitHub-Repositorys pushen.
2. vercel.com → Add New Project → Repository wählen.
3. Framework Preset: Other. Build Command und Output Directory leer lassen.
4. Deploy.

Adressen: `/`, `/ueber-mich`, `/impressum`, `/datenschutz`, `/agb`, `/widerruf`.
